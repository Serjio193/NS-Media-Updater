# Reference projects

These projects are useful for studying approaches and behavior. They are not vendored into this repository and are not treated as dependencies by default.

## Areas to study

### DBI

Focus:
- MTP storage layout
- installed games exposure
- SD/NAND install destinations
- device behavior during transfer

### NXSyncDBI

Focus:
- how a Windows-side client discovers and traverses DBI MTP
- installed title synchronization concepts
- practical MTP edge cases

### SwitchGameCatalog

Focus:
- local library organization
- metadata/cache flow
- game card UX
- package/version relationships

### Switch Library Manager

Focus:
- package classification
- Title ID/version organization
- identifying missing updates/DLC

## Rule

We use reference projects to understand the problem faster. We do not copy source code from a repository that does not grant permission for that use.
